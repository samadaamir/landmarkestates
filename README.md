# LANDMARK 🏡

A modern and responsive **real estate website** built with **Next.js**. LANDMARK is designed to provide a clean, premium interface for discovering properties, exploring locations, and connecting with real estate agents.

## ✨ Features

* 🏠 Modern real estate homepage
* 🏘️ Property listings
* 📍 Property locations
* 👨‍💼 Agent information
* 🔍 Property search interface
* 📱 Fully responsive design
* 🎨 Modern UI with reusable components
* ⚡ Fast page navigation with Next.js
* 🧩 Component-based architecture

## 🛠️ Technologies Used

* **Next.js**
* **React.js**
* **Tailwind CSS**
* **JavaScript**
* **HTML5**
* **CSS3**

## 📂 Project Structure

```text
landmark/
├── public/
├── src/
│   └── app/
│       ├── components/
│       ├── page.js
│       ├── layout.js
│       └── globals.css
├── package.json
└── README.md
```

Navigate into the project:

```bash
cd landmark
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```

## 🎯 Project Goal

The goal of LANDMARK is to create a professional real estate frontend while practicing modern **Next.js development**, responsive UI design, reusable React components, and clean project structure.
